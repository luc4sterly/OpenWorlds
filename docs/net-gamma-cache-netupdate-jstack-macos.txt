CONCLUSION (real evidence, without making up the exact reason for the
timing difference between (A) and (B) - it depends on the network's
answer when loading the server table of GroundZero/GroundZero.world, a
real multi-user world (RestartAt in worlds.ini), not on a threading
bug):

1. The Cache/NetUpdate thread model DOES run natively on macOS without
   Xvfb: "File Downloader N" (CacheEntry.run) does real network I/O
   through NIO (SocketDispatcher.read0), "Thread-0" (NetUpdate.run) does
   its own periodic poll through Thread.sleep, "Thread-1"
   (BackgroundLoader.run) waits on its queue - all three start and run
   without native exceptions or macOS-specific AWT/threading failures.
   There is no evidence of a deadlock: every wait() in the trace has a
   matching notify() in the code (CacheFile.waitUntilLoaded is released
   by CacheEntry when the download finishes - seen in (B), where the
   same code path runs and the process goes on instead of freezing).
2. What DOES block (by design, not a bug) is the application thread
   "Gamma Main": URLSelfLoader.syncBackgroundLoad literally does a
   SYNCHRONOUS load on a background loader - it blocks on purpose
   waiting for the result of a real download before it goes on building
   the console. If that download takes long or the server does not
   answer, Gamma's whole start stays there (seen in (A)); if it resolves
   quickly (quick failure or quick success), it goes on (consistent with
   (B), which prints nothing more between the ActiveX wall and the exit,
   but does not hang either).
3. The whole JVM depends on this because the real "main" thread (the
   one java invokes) does Gamma.main -> Thread.join() WITHOUT a timeout
   on the worker thread "Gamma Main" (Gamma.java:221) - that join is what
   keeps the process alive while "Gamma Main" lives, and it is
   consistent with exit 0 in (B): as soon as "Gamma Main" finishes its
   iteration (with or without a window shown), the join is released and
   the process exits cleanly - none of this is macOS-specific, it is the
   real design of the 2004 client.
